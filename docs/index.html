Arduino 取放分拣机器人项目展示

基于 Arduino Mega 2560 的移动取放/分拣机器人公开展示版：用有限状态机、合成传感器日志和指标复盘展示嵌入式控制与联调能力。

查看 GitHub 仓库 架构说明 面试讲解

展示模块

有限状态机
离开仓位、巡线、目标确认、抓取、颜色识别、分类投放、回程复位。
传感器联调
巡线误差、超声波距离、颜色置信度、舵机角度和串口遥测。
控制输出
PWM 差速修正和状态切换事件，便于复盘任务流程。
指标复盘
用 Python 解析合成日志，统计完成步数、状态占比、巡线误差和遥测完整率。

项目状态

模块公开展示状态边界说明
Arduino FSM提供 sanitized sketch skeleton不是现场完整调参版本
巡线与目标确认用合成日志展示接口和指标不声明真实硬件性能
颜色识别与投放展示状态流和置信度字段不包含真实传感器标定表
日志分析可运行，有 pytest 覆盖只用于公开 demo 复盘

本地运行

pip install -e ".[test]"

python scripts/run_demo_pipeline.py

pytest

合规边界

该仓库是公开展示版，不包含真实私有硬件日志、账号信息、内部路径或完整现场调参代码。所有日志和指标均为 synthetic/demo 数据。
