# 面试讲解要点

## 30 秒版本

这个项目是一个基于 Arduino Mega 2560 的移动取放/分拣机器人。我负责核心任务流程和控制逻辑，用有限状态机组织离开仓位、巡线、目标确认、抓取、颜色识别、按颜色投放和回程复位，并围绕传感器阈值、舵机角度、转向延时和目标检测距离做联调。

## 2 分钟版本

系统由直流电机驱动、巡线传感器、超声波、颜色识别、舵机机械臂和串口遥测组成。控制上没有把逻辑写成零散 delay，而是拆成状态机，每个状态只负责一类动作和退出条件。调试时重点看三类问题：巡线误差是否稳定、目标距离是否可靠、抓取和投放动作是否能重复。公开仓库用合成日志和 Python 指标复盘这些工程问题，避免公开真实私有代码和现场数据。

## 可深挖问题

- 为什么用有限状态机：任务阶段清晰，便于定位卡在哪个状态。
- 如何处理巡线误差：用误差到 PWM 差速修正的轻量控制逻辑。
- 如何提高颜色识别可靠性：多样本投票和置信度阈值。
- 如何做联调复盘：记录状态、距离、颜色、舵机角度、PWM 和事件，再用脚本汇总。
